# REIZDIO v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild REIZDIO on a modern stack at the repo root, keeping the blob visualizer and identity. Show only stations the visualizer can read, and ship Recents, Saved, About, search, mobile/lock-screen controls and share links.

**Architecture:**
- Server-only Radio Browser client plus stream verification behind Next route handlers.
- A singleton browser audio engine (one audio element, one AudioContext) feeds a framework-agnostic three.js visualizer.
- UI state lives in one Zustand store. Recents are in localStorage; Saved is a fresh Supabase table.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript strict, Tailwind CSS 4, three.js 0.186, Zustand, `@supabase/ssr` + `@supabase/supabase-js`, Vitest + Testing Library (jsdom), Playwright, npm.

**Spec:** `docs/superpowers/specs/2026-10-23-reizdio-v3-design.md`

## Global Constraints

- **Node:** this machine's shell has no node on PATH. Prefix commands with `export PATH="$HOME/.nvm/versions/node/v24.21.0/bin:$PATH"`. CI uses Node 24.
- **Layout:** the app lives at the repo root. `client/` and `server/` are deleted by the end of Task 1. Import alias is `@/*` → repo root.
- **Station identity:** a station is keyed by Radio Browser's `stationuuid`, exposed as `Station.id`.
- **Playable:** a station is playable iff `streamUrl` starts with `https:` and a request with `Origin: https://reiz.live` returns an `Access-Control-Allow-Origin` header. Timeout 3000 ms. Verdict cache TTL 24 h. Lists over-fetch 150 and return at most 50 playable.
- **Recents:** localStorage key `reizdio:recents`, max 20, newest first, de-duplicated by `id`.
- **Supabase:** table `saved_stations(user_id uuid, station_id text, station jsonb, created_at timestamptz)`, PK `(user_id, station_id)`, RLS restricted to own rows. Env vars stay `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` (already set in Vercel).
- **Identity:**
  - Title "REIZDIO".
  - Font PP Neue Montreal (Thin 200, Book 300, Medium 400, Bold 700) from `public/fonts/`.
  - Background `hsl(0 0% 3.9%)`, foreground `hsl(0 0% 98%)`, muted `hsl(0 0% 63.9%)`, accent red `#ee2647`.
  - Keep the marquee station name in the play bar.
- **Blob:** keep `iridescentVertexShader` / `iridescentFragmentShader` from `client/shaders/shaders.ts` and `IcosahedronGeometry(0.8, 64)`, camera FOV 70 at z=3, ACES tone mapping, rotation x=t·0.5, y=t·0.25. The current shader `time` uniform effectively advances at ≈2× wall-clock seconds; keep that speed.
- **Removed:** socket.io, ytdl-core, ytpl, dat.gui, figlet, simplex-noise, radio-browser-api, react-audio-player, standardized-audio-context, `@next/font`, the `/darkside` route.
- **Mobile:** layout must work at 360 px wide; tap targets ≥ 44 px.
- **three.js:** any task touching `visualizer/` reads the relevant `~/.claude/skills/threejs-*/SKILL.md` files first (r186 APIs).
- **Ship:** Vercel previews come from `v3`. Never push to `main`. Pushing `v3` requires the user's go-ahead.

## Review Focus

1. **Radio Browser unreachable or slow:** the API responds 502 within ~8 s; the UI shows an error with a Retry button, not an endless skeleton. (Test in Task 4 and Task 7.)
2. **Every candidate fails verification:** the list is empty; the UI shows "No stations for this combo" with an "Any language" action. (Tests in Task 3 and Task 7.)
3. **A listed station dies at play time:** skip to the next. If every station in the list fails in a row, stop and show a message instead of looping forever. (Test in Task 5.)
4. **Rapid switching and autoplay blocks:**
   - Only the last-selected station plays.
   - An `AbortError` from a superseded `play()` is ignored.
   - `NotAllowedError` puts the UI in a "tap to play" state.
   - Neither marks the station bad.

   (Tests in Task 5.)
5. **Unknown or removed station id in a share link:** `/s/<id>` renders a friendly "Station not found" with a link home. The OG image falls back to a generic REIZDIO card; nothing crashes. (Test in Task 14.)
